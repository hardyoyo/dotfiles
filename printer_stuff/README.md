# PPD FILES

## Where to find
https://www.openprinting.org/download/PPD/

## How to install
To install any ppd file on a Mac, ensure it is gzipped, then copy it to this folder:

`/Library/Printers/PPDs/Contents/Resources/`


## Example

`cp Samsung_ML-2850_Series.ppd.gz /Library/Printers/PPDs/Contents/Resources/`
